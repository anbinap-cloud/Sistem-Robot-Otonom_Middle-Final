# Sistem-Robot-Otonom_Middle-Final
Menggunakan 3 robot dengan 1 role pada masing-masing robot:  Role 1: Penjaga gawang (pilih 1 gawang) Role 2: Penendang bola Role 3: Partisipator, minimal bergerak random/script default dari CoppeliaSim, atau kreasi sendiri Bola, robot, gawang dan semua objek yang lain datanya boleh di ambil (posisi, kecepatan, dll) menggunakan API
